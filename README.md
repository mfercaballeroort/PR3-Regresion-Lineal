# PR3-Regresion-Lineal

Proyecto realizado como parte de la práctica PR3 de Analista de Sistemas ORT Belgrano.

## Objetivo

Aplicar los conceptos fundamentales de regresión lineal para construir, evaluar e interpretar modelos predictivos.

## Contenidos

- Preparación de datos
- Variables predictoras y objetivo
- Regresión lineal
- Entrenamiento y predicción
- División en conjuntos de entrenamiento y prueba
- MAE
- MSE
- RMSE
- R²
- Visualización de datos y recta de regresión
- Interpretación de resultados
- Limitaciones del modelo

## Ejercicios

El repositorio contiene cinco ejercicios prácticos y un desafío final:

1. Conceptos básicos de regresión lineal
2. Predicción
3. Precio de viviendas
4. Evaluación del modelo
5. División train/test
6. Desafío: kilómetros recorridos y consumo de combustible
